# Petualangan Laut Pokémon

Mini-game Pokémon bertema laut dan dinosaurus untuk anak 5 tahun, dengan petunjuk suara berbahasa Indonesia. Bisa dipasang di iPhone dan Android dan dimainkan tanpa internet.

Game diterbitkan otomatis ke GitHub Pages lewat workflow `.github/workflows/pages.yml` setiap ada perubahan di `main`. Aktifkan sekali di *Settings → Pages → Source: GitHub Actions*.

Pasang di HP: buka alamat Pages di Safari (iPhone: Bagikan → Tambah ke Layar Utama) atau Chrome (Android: ketuk **📲 Pasang di HP** → Instal).
